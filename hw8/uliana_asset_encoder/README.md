# HW8 · Ульяна Целищева · представление активов FAR-Trans

Сравнение TF-IDF и frozen Qwen3-Embedding-0.6B в первом этапе Hybrid из HW7. Обе ветки ранжируют полный допустимый каталог по косинусу. Меняется способ получения вектора актива.

## Запуск

Нужны Python 3.11, исходный [FAR-Trans.zip](https://researchdata.gla.ac.uk/1658/) и командный архив Алины `team5_alina_t4_protocol_check.zip`. Оба архива читаются напрямую. Команда ниже выполняется из `hw8/uliana_asset_encoder` с путями к локальным копиям архивов.

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
HF_HOME="$PWD/.hf-cache" .venv/bin/python run_experiment.py \
  --alina-zip /path/to/team5_alina_t4_protocol_check.zip \
  --far-trans-zip /path/to/FAR-Trans.zip \
  --allow-download --output-dir outputs/reproduction
.venv/bin/python verify_outputs.py outputs/reproduction
```

Для повторения среды на macOS arm64 можно установить зависимости из `requirements-macos-arm64.lock.txt`. Для прогона с локальными файлами модели замените `--allow-download` на `--model-dir /path/to/model`. При загрузке используются контрольные суммы весов и токенизатора закреплённой ревизии. Каждый запуск записывается в новую папку.

## Сравнение

- Из протокола Алины берутся 100 пользователей и 767 активов. Данные модели предшествуют 1 июня 2021 года. Цели — уникальные допустимые покупки в окне `[2021-06-01, 2021-07-01)`. Повторы разрешены, точные дубли и отрицательные идентификаторы транзакций удаляются.
- Энкодеры получают `assetCategory`, `assetSubCategory`, `sector` и `industry` последнего доступного снимка. Пропуски и конфликты на дату снимка заменяются на `[MISSING]`. TF-IDF обучается на всём каталоге. Qwen кодирует уникальные описания с last-token pooling. [Ревизия модели](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B/tree/97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3)
- В обеих ветках профиль — среднее нормированных векторов уникальных активов, купленных до отсечки. Ключи сортировки — косинус с округлением до 12 знаков по убыванию, число исторических покупателей по убыванию, ISIN по возрастанию.
- Четыре классических baseline берутся из сохранённых результатов Алины. Скрипт сверяет метрики по сохранённым Top-10. Штатный CBF использует другой набор признаков и частоты покупок.

В проверенном прогоне nDCG@10 TF-IDF и Qwen составил **0,0225 / 0,0276** по всем 100 пользователям и **0,2043 / 0,2510** по 11 пользователям с непустой truth. Полная таблица и параметры создаются в `comparison.md` и `run_manifest.json`. В папке каждой ветки сохраняются Top-10, per-user метрики и векторы. Эти файлы относятся к локальным результатам.
